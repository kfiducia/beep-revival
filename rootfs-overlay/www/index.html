Update firmware

Pick the single signed .bin from a Beep release — its signature is bundled in and verified against the device key before flashing. If an update won't boot, the device auto-recovers — no cable. To install an unsigned build, triple-tap the knob on the device (physical presence required — a remote attacker can't).
